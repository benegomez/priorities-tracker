# PR #11 — US-011: AI Weekly Team Summary

## Summary

Implements the MVP AI feature: a weekly team summary generated by OpenAI for managers. The endpoint collects team data (CRS, priorities, tasks), builds a structured prompt, calls OpenAI, and returns an executive summary in Spanish. Includes weekly cache (1 call per week per manager) and fail-safe fallback.

## Key Design Decisions

1. **Cache strategy** — First call generates and persists in `ai_summaries`. Subsequent calls return cache without calling OpenAI. `regenerate=true` invalidates cache.

2. **Fail-safe** — If OpenAI fails (timeout, error, no API key), returns a calculated fallback summary. Fallback is NOT cached (so next attempt can try OpenAI again).

3. **Cost control** — Max 1 OpenAI call per manager per week (~$0.001/week with gpt-4o-mini). Cache prevents repeated calls.

4. **Origin badges** — UI clearly indicates: 🟢 "Generado por IA", 🔵 "Desde cache", ⚪ "Resumen automático (sin IA)".

## Cache Flow

```
First visit  → OpenAI → persist → cached=false, fallback=false
Second visit → return cache → cached=true (no OpenAI call)
Regenerate   → delete cache → OpenAI → persist → cached=false
OpenAI fails → fallback → cached=false, fallback=true (NOT persisted)
```

## API Contract

```
POST /api/v1/ai/team-summary
Body: { "regenerate": false }
Response: { summary, generated_at, model, data_snapshot, fallback, cached }
```
